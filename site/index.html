Why DiffCode

Your IDE can show a Git diff. It's just heavy.

Features

Everything a code review needs. Nothing it doesn't.

DiffCode is a Git diff viewer first and a Git client second. Every feature is about reading a change, deciding what to keep and committing it.

Partial commits

Commit only the lines you choose.

Untick a hunk, or select a few lines and leave them out. Only the rest is committed; what you left out stays in your working tree for the next commit.

  • Amend or undo the last commit; ⌥⌘K commits and pushes.
  • Git hooks run as usual, and their output is shown when they fail.
  • Roll back a file or a single change. ⌘Z brings it back.

Made for coding agents

See what your coding agent changed.

Run Claude Code, Codex or any command-line agent in the built-in terminal. Every file it touches shows up in the diff above as it works: fix a line, roll back what you don't want, commit what you approve.

Git history

Branches and history, one click away.

Click the branch name for the Git graph in a dropdown — branches, tags and remotes on the left, commits on the right. Check out, merge, rebase, cherry-pick, revert or reset, each with Undo.

Merge conflicts

Resolve merge conflicts one at a time.

Every conflict gets Keep HEAD, Take Incoming and Both. A banner keeps the merge or rebase in view, with Continue, Skip and Abort, and Commit Merge when you are done.

All your repositories

Every repository in one window.

The sidebar lists your projects with branch, ahead and behind, and change counts. Search Everywhere with ⇧⇧, go to a file with camel-case matching, or find in files across every project with git grep.

Details

The details of a good diff viewer.

Edit in place

Type into the working-tree side of the diff. It saves after a second of idle and keeps encoding and line endings byte for byte.

Side-by-side or unified diff

Word-level highlights, curved connectors and an overview bar. ⌥⌘V switches between the two views.

Syntax highlighting for your stack

Kotlin, Java, Swift, TypeScript, Python, Go, Rust, C/C++, C#, Dart and more. Image diffs too, and you can ignore whitespace.

Stash

Stash local changes, then apply, pop or drop them from a list. Dropping a stash can be undone.

Open from the terminal

Run dif in a repository, or dif ~/work/app ~/work/lib, to open it in DiffCode. Or drag folders into the sidebar.

Light or dark, English or 中文

Dark, light or follow the system. Pick the fonts for code and for the terminal, and size code, interface and terminal separately. The language follows your system.

Privacy

Your code stays on your computer.

No account, no telemetry

DiffCode goes online only when you fetch, pull or push — through your own git, credentials and SSH agent — and to check for updates.

Read-only until you act

Refreshing, diffing and searching never write to your repository or take index.lock, so it can stay open next to your IDE and agents.

Everything can be undone

Rollbacks, deletes and history edits come with Undo. Deleted files go to the Trash or the Recycle Bin, and risky steps ask first.

FAQ

Frequently asked questions

Something else? Ask in GitHub Discussions or open an issue.

Is DiffCode free?

Yes. DiffCode is free and open source under the GNU General Public License v3.0. There is no account, subscription or paid tier, and the source code is on GitHub.

What is DiffCode for?

It is a Git diff viewer and Git client for reviewing and committing changes on a Mac or a Windows PC. It shows side-by-side or unified diffs, lets you edit and commit selected lines, and handles branches, history, stash and merge conflicts. It is not a code editor or an IDE.

How is it different from opening my IDE?

Opening a project in an IDE means waiting while it loads its plugins and indexes the code, and it often takes several gigabytes of memory. DiffCode keeps only the diff, the commit, the history and a terminal, so it opens quickly and uses about 30–50 MB.

How big is DiffCode?

The installer is about 4 MB on either system, and the installed Mac app is about 8 MB. DiffCode is a native app (AppKit on the Mac, Win32 on Windows) with no bundled browser engine or runtime, which is also why it starts quickly and uses about 30–50 MB of memory.

Can I review changes made by Claude Code or Codex?

Yes. Run the agent in DiffCode's built-in terminal, or anywhere else, and every file it changes appears in the diff as it works. Compare with Branch shows everything since the agent's branch split off.

Can I commit only part of a file?

Yes. Untick a hunk, or select lines and leave them out of the commit. Those changes stay in your working tree for later.

Does DiffCode change my repository?

Not until you act. Refreshing, diffing and searching never write to the repository or take index.lock, so DiffCode can stay open next to your IDE, terminal and agents.

Which Macs does DiffCode run on?

Any Mac running macOS 14 Sonoma or later, with Apple Silicon or an Intel processor. The main download is for Apple Silicon; Intel Macs have their own, DiffCode-Intel.pkg. Both are signed and notarized by Apple and keep themselves up to date.

Does DiffCode run on Windows?

Yes. DiffCode for Windows runs on 64-bit Windows 10 (1809) or Windows 11 and uses Git for Windows. It is a native app with the same features, and its built-in terminal runs PowerShell or cmd. The installer is not code-signed, so SmartScreen may warn the first time you run it: choose More info, then Run anyway.

How does DiffCode update?

On the Mac it checks for updates and installs new versions from inside the app. On Windows it tells you when a new version is out and opens the download page. You can also download the latest release from GitHub at any time.
