**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.4/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.4/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.4.4/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### New

- **Repositories inside WSL (Windows, [#7](https://github.com/ihou/DiffCode/issues/7)).** A folder opened as `\\wsl.localhost\Ubuntu\home\you\project` (or `\\wsl$\…`) used to be refused. Git for Windows takes such repositories as another user's and is slow over the share. DiffCode now runs the distro's own git through `wsl.exe`, with the distro's configuration, hooks and credentials, and puts paths back the way you opened them. Changes still show by themselves: Windows reports no file changes on the share, so DiffCode looks again every few seconds and whenever its window comes back to the front. The terminal opens the distro's shell in that folder and is named after the distro. Git has to be installed in the distro (`sudo apt install git`); DiffCode says so if it isn't.

### Fixes

- **Why a folder was refused.** When git won't open a folder, DiffCode now shows git's reason instead of "No Git repository found there". For a repository that belongs to another user, it offers to copy the command that trusts it. This is for both the Mac and the Windows app.

### 新功能

- **WSL 里的仓库（Windows 版，[#7](https://github.com/ihou/DiffCode/issues/7)）。**以前用 `\\wsl.localhost\Ubuntu\home\you\project`（或 `\\wsl$\…`）打开的文件夹会被拒绝：Git for Windows 认为这类仓库属于别的用户，而且通过共享访问很慢。现在 DiffCode 通过 `wsl.exe` 调用发行版自己的 git，用的是发行版里的配置、钩子和凭据，显示的路径也和你打开时的一样。改动照样会自动出现：Windows 收不到共享上的文件变化通知，所以 DiffCode 每隔几秒看一次，窗口回到前台时也会立刻看一次。内置终端会在这个文件夹里打开发行版的 shell，标签显示发行版名。发行版里需要装有 git（`sudo apt install git`），没装时 DiffCode 会提示。

### 修复

- **说明文件夹被拒绝的原因。**Git 拒绝打开某个文件夹时，DiffCode 现在会显示 git 给出的原因，不再只说“这里没有找到 Git 仓库”。如果仓库属于另一个用户，还可以一键复制信任它的命令。Mac 版和 Windows 版都有这项修复。

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
