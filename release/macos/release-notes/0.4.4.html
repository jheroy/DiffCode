DiffCode 0.4.4

修复

  • 说明文件夹被拒绝的原因。Git 拒绝打开某个文件夹时，DiffCode 现在会显示 git 给出的原因，不再只说“这里没有找到 Git 仓库”。如果仓库属于另一个用户，还可以一键复制信任它的命令。

Fixes

  • Why a folder was refused. When git won't open a folder, DiffCode now shows git's reason instead of "No Git repository found there". For a repository that belongs to another user, it offers to copy the command that trusts it.
